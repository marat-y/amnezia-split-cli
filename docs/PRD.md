# amnezia-split-cli — PRD

Локальный CLI для безопасного управления сайтовым раздельным туннелированием AmneziaVPN на macOS без ручного редактирования JSON и импорта настроек. Публичная ниша — ручные и агентские операции, а не каталог сайтов или автообновление.

## Поведение

- Работает на macOS с AmneziaVPN и доменом настроек `org.amneziavpn.AmneziaVPN`.
- Источник локального списка — `~/.config/amnezia-split-cli/exceptions.json`; `--file` задаёт другой путь. Каталог можно переопределить через `XDG_CONFIG_HOME` или `AMNEZIA_SPLIT_CLI_CONFIG_HOME`.
- `amnezia-split-cli add HOST…` подхватывает текущие правила Amnezia, резолвит новые хосты в один IPv4, добавляет их и применяет список. Дубликаты по имени пропускаются. Ошибка резолва не меняет список.
- `amnezia-split-cli remove HOST…` подхватывает текущие правила и удаляет записи, у которых имя или IP совпал с аргументом. Отсутствующие записи не вызывают перезапуск.
- `amnezia-split-cli list [FILTER]` выводит локальный список; `--json` возвращает машиночитаемый массив.
- `amnezia-split-cli sync` объединяет JSON с текущими правилами Amnezia, сохраняя записи, добавленные через GUI. `sync --replace` — единственная операция, которая намеренно заменяет весь список содержимым JSON.
- `--dry-run` показывает результат без записи JSON и настроек. `--no-restart` только обновляет JSON и не обращается к приложению для применения настроек.
- `backup [PATH]` сохраняет полный plist с правами 0600. `restore [PATH]` восстанавливает только `Conf.ExceptSites` и синхронизирует JSON.
- Перед обычным применением сохраняется резервная копия plist. Amnezia закрывается перед `defaults import` и открывается после него; VPN поднимается через `autoConnect`.
- Если актуальный список уже применён, приложение не перезапускается. При ошибке применения исходные настройки и JSON восстанавливаются.
- Личный wrapper `amnezia-sync HOST…` продолжает работать как add, вызов без аргументов — как sync.

## Ограничения

- Только macOS и сайтовые исключения AmneziaVPN.
- При добавлении hostname получает один IPv4; автоматической ротации DNS, IPv6 и расширения CIDR нет.
- Формат `Conf.ExceptSites` внутренний и может измениться в новых версиях AmneziaVPN.

## Реализация

Исходный `~/.local/bin/amnezia-sync` перенесён в отдельный проект на Python и стандартной библиотеке. `plistlib` читает и пишет настройки macOS без зависимостей. Тесты используют временные файлы и mock-объекты, реальная Amnezia им не нужна. CI запускает их на macOS с Python 3.9 и 3.13.

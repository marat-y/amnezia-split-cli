# amnezia-cli — PRD

Нужен локальный CLI для управления сайтовым раздельным туннелированием AmneziaVPN без ручного редактирования JSON и импорта настроек.

## Поведение

- Работает на macOS с AmneziaVPN и доменом настроек `org.amneziavpn.AmneziaVPN`.
- Источник истины — `~/Downloads/amnezia-ru-domains.json`, список объектов `hostname` и `ip`.
- `amnezia-cli add HOST…` резолвит новые хосты в IPv4, добавляет их и применяет список. Дубликаты по имени пропускаются. Ошибка резолва не меняет список.
- `amnezia-cli remove HOST…` удаляет записи, у которых имя или IP совпал с аргументом, и применяет список. Отсутствующие записи не вызывают перезапуск.
- `amnezia-cli list [FILTER]` выводит список по имени; необязательный фильтр ищет подстроку в имени и IP.
- `amnezia-cli sync` полностью заменяет `Conf.ExceptSites` в настройках содержимым JSON.
- Перед изменением настроек сохраняется резервная копия plist. Amnezia закрывается перед `defaults import` и открывается после него; VPN поднимается через `autoConnect`.
- Если актуальный список уже применён, приложение не перезапускается. При ошибке применения после add/remove исходный JSON восстанавливается.
- Старый `amnezia-sync HOST…` продолжает работать как add, вызов без аргументов — как sync.

## Реализация

Перед разработкой найден существующий `~/.local/bin/amnezia-sync`: он уже умеет добавлять хосты, сохранять plist и перезапускать Amnezia. Решение — перенести его в отдельный проект на Python и стандартной библиотеке, сохранив формат файла и совместимость вызовов. Ruby здесь не даёт преимуществ: исходная реализация на Python, а `plistlib` покрывает чтение и запись настроек macOS.
